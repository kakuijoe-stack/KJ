# ALVELLA(アルベラ)ウェブサイト

京都・烏丸御池の髪質改善&ヘッドスパサロン **ALVELLA** の公式サイト一式です。
静的HTMLのみで構成されており、レンタルサーバー・GitHub Pages・Netlify等にそのまま置けば公開できます(サイト上で決済は行わないため静的ホスティングで問題ありません)。

## 構成(1ページ統合・iPhone最適化)

| ファイル | 役割 |
|---|---|
| `index.html` | **統合サイト** — サロン/パーク/採用の3ビューを画面下部の固定タブバーで切り替えるSPA風の1ファイル。ハッシュルーティング(`#park` `#recruit` `#セクションID`)対応。ボトムシート型の全セクションメニュー付き |
| `park.html` / `recruit.html` | 旧URL互換のリダイレクト(`index.html#park` / `#recruit` へ転送) |
| `assets/` | 写真(圧縮済み・300KB以下)+動画(intro.mp4 / headspa.mp4) |

## 設計方針(調査に基づく)

- **予約導線**: どのページからも1タップで予約へ。WEB予約(ホットペッパー)を主役に、Instagram DM・電話を併設。モバイルは画面下部固定バー
- **役割分担**: ポータル(HPB/Hairbook/QJナビ)=入口、公式サイト=信頼構築のハブ、採用サイト=分離(相互リンク)
- **ローカルSEO**: title「烏丸御池の髪質改善・ヘッドスパ」型、JSON-LD(HairSalon)、NAP統一前提の表記
- **薬機法・景表法**: 「治す/修復/再生/改善する(説明文)」不使用。状態表現(抑える/整える/導く)に統一。効果保証なし。数値は出典注記付き
- **表示速度**: 画像は全て圧縮済み+width/height指定+lazy、ヒーローのみpreload
- **動画**:
  - 紹介動画 → 公式サイトのヒーロー背景に実装済み(assets/intro.mp4、26秒・無音ループ・3.2MB・reduced-motion対応)
  - ヘッドスパ動画 → ヘッドスパ・頭浸浴セクションにリール風で実装済み(assets/headspa.mp4、無音ループ・1.6MB)
  - スタッフインタビュー×2 → 採用サイト「先輩たちの声」に差し込み予定(TODOコメントあり)
  - 道順動画 → アクセスセクション+Googleビジネスプロフィールに差し込み予定
  - おもてなし表現動画 → PARK別館のヒーロー背景に差し込み予定

## デプロイ

ブランチ `claude/alvella-recruitment-homepage-ugxv0g` へのプッシュで
`.github/workflows/deploy-pages.yml` が自動デプロイします(反映まで1〜2分)。
※ `github-pages` 環境の Deployment branches に当ブランチを許可済みであること。

Vercelに切り替える場合は `vercel.json` 同梱済み(インポート後、Production Branchを当ブランチに設定)。

## PARKページの拡張ロードマップ(API連携)

`index.html` のPARKビューには、今後の拡張の受け皿となる枠を実装済み(`#p-live` / `#p-ugc`。HTML内にTODOコメントあり):

- **ライブ・パーク情報**(準備中表示中): アトラクション待ち時間 / 天気+髪の広がり注意報 / ショー・パレード予定 / スタッフ監修モデルコース。静的サイトのままクライアントサイドJSで公開APIを叩く実装が可能。widget内をJSで差し込む設計

## 公開後の運用(調査からの推奨)

- 料金・営業時間の変更は**即日**サイトとGoogleビジネスプロフィール両方に反映(NAP不一致はローカル検索評価を下げる)
- HairbookやQJナビ等のプロフィール欄に公式サイトURLを掲載してもらう(被リンク=知名度評価)
- Googleビジネスプロフィールの口コミには24時間以内目安で返信
- 月1回以上の更新(お知らせ/Instagram)。余力があれば「京都 湿気 うねり対策」等の悩み系コラムを月2〜4本
- GA4+Search Consoleを導入し、予約ボタンクリックをキーイベントに設定
