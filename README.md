# ALVELLA(アルベラ)採用サイト

京都・烏丸御池の髪質改善&ヘッドスパサロン **ALVELLA** の採用特化ホームページです。
`index.html` 1ファイルで完結する静的サイトなので、そのままレンタルサーバーや GitHub Pages・Netlify 等に置くだけで公開できます。

## サイトの設計方針(調査に基づく)

美容師求職者・美容学生の調査データと有名サロン採用サイトの分析をもとに、次の方針で設計しています。

1. **世界観 × 条件の透明性の両立** — 求職者が最も知りたいのは給与(67.8%)と休日(44.5%)。冒頭の「数字で見るALVELLA」で条件を先に全部見せ、その上で和モダン×上質な世界観(生成り×墨×深緑×金茶、明朝体)でサロンのブランドと一貫させています。京都・関西の競合採用サイトは条件羅列型が多く、この両立自体が差別化になります。
2. **「まずは見学」の低ハードルCTA** — 美容師の就職はサロン見学が意思決定の中核。応募一択にせず「見学(私服OK)>DM相談>応募」の3段階導線を全編に配置しています。
3. **不安の先回り解消** — デビュー時期(最短1年半)、営業時間内レッスン、休日、FAQで、アシスタントの典型的な離職理由・不安に先に答えています。
4. **モバイルファースト** — 美容学生はほぼスマホ閲覧。1カラム設計+画面下部の追従CTAバー。
5. **Googleしごと検索対応** — JobPosting構造化データ(JSON-LD)を実装済み。「京都 美容師 求人」等の検索流入を狙えます。

## 公開前に必ず確認してほしいこと(重要)

掲載内容は求人媒体(QJナビ/HPBワーク等)の公開情報のみを使用し、**媒体間で食い違いがあった情報や未確認の情報は掲載していません**。以下をオーナー(角井さん)に確認のうえ、確定したら追記してください。

| 項目 | 状態 | 備考 |
|---|---|---|
| 代表メッセージ本文 | **草稿(要本人確認)** | 公開情報から作成した下書き。必ず本人の加筆・承認を得ること |
| 営業時間 | 未掲載 | 媒体により「9:00〜19:00」と「9:00〜17:30」の2表記があり保留 |
| 定休日の正式表記 | 「月・火」で掲載 | 一部媒体に「月曜・第三火曜」表記あり。要確認 |
| 電話番号・応募用メール | 未掲載 | 確認でき次第、最終CTAセクションに追加 |
| 公式LINE | 未掲載 | あればDM導線と併設推奨(見学申込率が上がる) |
| 写真素材 | CSSプレースホルダで代替 | 内観・施術風景・スタッフ笑顔・オーナーポートレートの差し替え推奨(HTML内に `TODO` コメントあり) |
| 先輩インタビュー | 「準備中」表示 | 取材後に voice セクションを差し替え |
| モデル年収・昇給実績 | 未掲載 | 実績ベースの数字が用意できれば応募率がさらに上がる |
| スタッフ在籍数 | 未掲載 | 媒体間で表記差(7名 or 4名)のため保留 |
| 求人の掲載期限 | — | JSON-LD の `validThrough` を運用に合わせて追加推奨 |

## 使い方

- プレビュー: `index.html` をブラウザで開くだけ
- 写真の差し替え: HTML内の `<!-- TODO: ... -->` コメントの箇所に `<img>` を配置
- 文言修正: すべて `index.html` 内に直書きしています
